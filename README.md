# Библиотека ESKD_InAmp

Библиотека проекта инструментального усилителя содержит УГО и четыре типа посадочных мест. УГО сохранены из исходной схемы; посадочные места извлечены из исходной платы, поэтому геометрия и нумерация контактов совпадают с проектом.

## Состав

- `ESKD_InAmp.kicad_sym`: резистор, SGM8249, контрольная точка, восьмиконтактный интерфейс, метки питания и PWR_FLAG.
- `footprints.pretty/R_0805.kicad_mod`: резистор 0805.
- `footprints.pretty/TSSOP14.kicad_mod`: корпус TSSOP-14.
- `footprints.pretty/TestPoint_5000.kicad_mod`: контрольная точка Keystone 5000.
- `footprints.pretty/Interface_2x4.kicad_mod`: составной интерфейс из двух рядов по четыре контакта с шагом 2,54 мм.

В проекте библиотека подключается как Git-сабмодуль в `libraries/eskd`. Пути в таблицах библиотек начинаются с `${KIPRJMOD}` и не зависят от имени пользователя или диска.

УГО основаны на переданном пользователем оформлении ЕСКД. Стандартные посадочные места происходят из библиотек KiCad в составе исходного проекта; условия их использования: https://www.kicad.org/libraries/license/.
